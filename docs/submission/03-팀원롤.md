## 협업 · 분업 방식

### 폴더 경계로 충돌을 막는 구조

담당자별로 주 작업 폴더를 나눠, 세 명이 동시에 작업해도 같은 파일을 건드릴 일이 거의 없게 했다.

| 담당 | 주 작업 폴더 |
|---|---|
| 전성민 | `docs/planning/`, `docs/governance/` |
| 김민주 | `data/drafts/`, `data/candidates/` |
| 최수정 | `src/`, `tools/`, `schema/`, `api/` |

### 결정 로그 기반 협업

기획 결정을 `DEC-` ID를 가진 항목으로 관리하고, 확정·보류·폐기 상태를 명시했다.
구현이나 콘텐츠 작업 중 규칙이 모호하거나 충돌하면 임의로 우회하지 않고 작업을 멈춘 뒤
기획 책임자의 확정을 받고 재개했다.

### 작업 기록 자동화

커밋 이력에서 `PROGRESS.md`를 자동 생성하고, 커밋 메시지에 담기 어려운 맥락은
개인별 세션 로그에 남겼다.

### 조작

기준: `DEC-INPUT-001` ~ `DEC-INPUT-009`

| 행동 | 입력 |
|---|---|
| 이동 | `WASD` (8방향) |
| 조준 | 마우스 커서 |
| 파종 · 수확 | `E` |
| 낫 공격 | 마우스 오른쪽 |
| 투척 무기 사용 | 마우스 왼쪽 |
| 투척 퀵슬롯 선택 | `1` ~ `5` |
| 투척 무기 순환 | 마우스 휠 |
| 회복 아이템 사용 | `Q` 짧게 누르기 |
| 회복 퀵메뉴 | `Q` 길게 누른 채 선택 후 놓기 |
| 일시정지 | `Esc` |

### 진행 흐름

기준: `DEC-RUN-012`

타이틀 → 이름 입력 → 튜토리얼 → 일차 시작 → 재배 단계 → 정비 단계 →
(습격일) 전투 전 대화 → 습격 전투 → 투항 대화 → 조우 결과 → … → 엔딩

### 종료 조건

- **실패**: 재배 또는 습격 중 플레이어 체력이 0이 되면 즉시 전체 런 실패 (`DEC-RUN-008`)
- **완료**: 마지막 습격의 조우 결과 처리 후 엔딩 판정으로 이동 (`DEC-RUN-013`)

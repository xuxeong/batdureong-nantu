# 작업 로그 — 최수정 (개발)

**Git 커밋에 남지 않는 것만 적는다.** 무엇을 바꿨는지는 `PROGRESS.md`와 diff에 이미 있다.

작성 형식 (해당 없으면 생략):

```
## YYYY-MM-DD 제목

**한 일** — 한두 줄

**왜 이렇게 했나** — 어떤 대안을 검토했고 왜 접었나

**AI가 잘못한 것** — 무엇을 어떻게 잡았나

**막힌 것** — 결정로그에 답이 없는 것. 기획 책임자에게 올릴 목록
```

`AI가 잘못한 것`과 `막힌 것`이 제일 중요하다. 8/8 제출 자료의
「AI 활용 기술 문서」와 「팀원 롤 기술서」를 쓸 때 이 기록이 그대로 재료가 된다.
일주일 뒤에 기억으로 복원하려 하면 대부분 잃어버린다.

이 파일은 개인 전용이라 다른 사람과 충돌하지 않는다.

스키마 31종을 만들면서 **DEC에 없는 문장 734개를 내가 지어냈다.** 필드마다 "기획자가

문제는 이게 스키마 파일 안에 있으면 **기획 책임자가 정한 것처럼 읽힌다**는 점이다.

이건 결정로그 어디에도 없는 내 판단이었다.

그리고 검증 규칙 2개(`wildlife.used_by_spawn_profile`,
`personality_profile.referenced_by_resident`)는 해당 DEC의 검증 목록에 아예 없는데
내가 추가했다.

전부 걷어냈다. 스키마에는 구조(필드명·자료형·범위·참조)와 근거 DEC ID만 남겼고,

**세운 기준**: 파일이 무엇이냐가 아니라 **내용이 누구 것이냐**로 판단한다.
게임 규칙·필드 정의·판정 방식은 기획 문서 소유라 인용만 하고, 저장소 구조·npm 명령·

**한 일**

  글로 더 강하게 쓰는 대신 실행 주체를 사람에서 CI로 바꿨다.
- **`if: github.actor != 'github-actions[bot]'`와 `[skip ci]`를 둘 다 걸었다.**
  봇이 만든 커밋이 다시 push 이벤트를 일으켜 무한히 도는 것을 막는다. 둘 중 하나만
  있어도 대개 막히지만 워크플로 트리거를 나중에 바꿀 때 한쪽이 무력해진다.
- **`fetch-depth: 0`이 필요하다.** `tools/progress.mjs`가 전체 커밋 이력을 읽는데
  Actions 기본 체크아웃은 얕은 클론이라 최근 커밋만 나온다.
- **세션 로그는 자동화할 수 없어서 규칙으로 남겼다.** "왜 그렇게 했나"와 "AI가 뭘
  잘못했나"는 diff에서 뽑아낼 수 없다. 대신 `CLAUDE.md`에 **묻지 말고** 쓰라고
  적고, 빠뜨리기 쉬운 조건 4가지를 나열했다. 확인을 받으려 하면 그 순간 안 쓰게 된다.

**AI가 잘못한 것**

오늘 "PROGRESS.md가 최신이 아니다"라는 지적을 받고 처음엔 CI가 실패했다고 봤다.
실제로는 CI가 정상이었고 봇 커밋(`a541c74`)이 원격에만 있었다. 로컬에서 `git fetch`를
안 해서 안 보였을 뿐이다. **로컬 상태를 원격과 같다고 가정하고 진단을 시작했다.**
하마터면 같은 내용을 로컬에서 다시 생성해 중복 커밋을 만들 뻔했다.

자동 생성 파일을 CI가 커밋하는 구조에서는 **작업 시작 전에 `git pull`이 필수**다.
안 하면 로컬 재생성분과 봇 커밋이 충돌한다.

**막힌 것**

없음. 배포·LLM 사용 여부는 7/31 항목 그대로 미확정.

## 2026-08-06 HUD 를 A1 배치로 (로드맵 9번)

**한 일**

**왜 이렇게 했나**

- **글자 토큰을 같이 올렸다.** 담당자가 *"기준 해상도 넣은 뒤로 크기가 달라졌다"*
  고 알려와 재봤더니, 8/5 캡처와 지금 화면의 비율은 **정확히 같았다** —
  캡처에서 보관함 패널 왼쪽 여백이 `--hub-pad` 와 같은 28px 에 떨어진다.
  바뀐 것은 비율이 아니라 **기준**이다. 무대 이전에는 UI 가 창 크기 그대로
  그려졌고, `DEC-UI-025` 이후로는 1920 좌표에 그려져 상자째 축소된다. 1280
  화면에서 14px 가 실제 9.3px 이 된다. **계산이 틀린 게 아니라 정한 수치가
  작았던 것**이고, 그래서 HUD 만이 아니라 기본 토큰을 올렸다. HUD 만 올리면
  정비 허브·대화창은 계속 작다.
- **픽셀 좌표를 CSS 에 적었다.** 보통은 피할 값인데 A1 부품은 테두리·홈·크림 판이
  **그림 안에** 이미 그려져 있다. flex 로 나누면 글자가 그 자리에 안 앉는다.
  무대가 1920 고정이고 월드 1단위 = 1픽셀이라(`DEC-ART-001`) 배율이 없어서
  실측 좌표가 그대로 맞는다. 에셋이 다시 오면 같이 고치라고 주석에 적었다.
- **셔터를 진하게 한 것은 HUD 를 숨기는 것보다 작은 수정이다.** 표지판이
  253×174 로 커지면서 셔터(0.94) 뒤로 `1일차` 가 비쳐 허브의 `소지금` 과 겹쳤다.
  정비 중 HUD 를 숨기는 쪽도 검토했는데, `DEC-UI-017` 이 HUD 를 "재배·습격 모두"
  로 정하고 정비가 그 둘 중 무엇인지는 안 정해서 **해석이 필요하다.** 셔터 색은
  `DEC-ART-001` 이 `layout.css` 를 원본으로 정한 값이라 해석 없이 끝난다.

**AI가 잘못한 것**

- **게이지를 폭 퍼센트로 채웠다.** 절대 배치라 퍼센트 기준이 그림 전체(911px)가
  되는데 홈은 왼쪽 613px 뿐이다. 남은 시간 96% 에서 게이지가 그림에 **박혀 있는**
  `남은 재배 시간` 글자를 덮었다. 에셋 안에 글자가 있다는 것을 안 보고 짰다.
  0~1 비율만 넘기고 기준 폭은 CSS 가 갖게 바꿨다.
- **`100 / 100` 이 카드에 안 들어간다는 것을 스크린샷 보고 알았다.** 그 자리가
  55px 이다. 확정문(`DEC-UI-017`)을 다시 읽으니 요구하는 것은 `현재 체력`의
  수치라 `100` 하나가 맞았다. **내가 넣었던 `/ 최대치` 가 확정문에 없던 추가였다.**
- **헤드리스 확인에서 "돌아다니면 안 죽겠지" 로 세 번 날렸다.** 실제로는 출현점이
  밭 가장자리라 돌아다니면 그쪽으로 걸어 들어간다. 가만히 서서 낫을 휘두르는
  쪽이 살아남았다. 추측으로 대책을 고르지 말고 실패한 실행의 조건부터 봤어야 했다.

**막힌 것** — 없다. `DEC-UI-017`·`018` 이 남은 시간의 형태를 정하지 않고
`DEC-ART-001` 로 위임해서 게이지 전환은 규칙 안이었다.

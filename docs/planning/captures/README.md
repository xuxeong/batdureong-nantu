# 구현 화면 캡처

A3·A4 목업을 **이미 구현된 배치**에 맞춰 뽑기 위한 참고용이다. 게임이 읽는 리소스가
아니므로 `assets/` 가 아니라 여기 둔다.

캡처 시점: 2026-08-06 · `develop` · 개발 빌드 · 1920×1080

| 파일 | 화면 | 찍은 상태 |
|---|---|---|
| `maintenance-hub.png` | 정비 허브 (`DEC-UI-020`) | 1일차 정비. 세 칸을 거둔 직후라 수확물이 들어 있다 |
| `maintenance-hub-filled.png` | 정비 허브 | 같은 화면에서 판매·구매·제작을 거쳐 무기가 든 상태 |
| `dialogue-modal.png` | 전투 전 대화 (`DEC-UI-007/008`) | 2일차 습격, 영순 |

## 이 캡처가 확정 배치다

8/5 캡처에는 *"HUD·필드는 목업 기준이 아니다"* 라는 경고가 붙어 있었다.
**그 두 가지가 8/6 에 끝나서 경고를 지웠다.**

- **HUD 은 A1 확정 배치다** (로드맵 실행 순서 9번). 표지판(일차 + 습격 예고) ·
  상단 가로 게이지 · 톱니바퀴 · 하단 좌측 플레이어 카드 · 하단 우측 퀵슬롯 5칸 +
  회복 칸. 크기는 `assets/final/ui/` 실측값이다.
- **필드도 A1 에셋이다** (8번). 배경 한 장 → 경작지·작물 → 수풀 앞 겹 3층으로 그린다.
- 아직 플레이스홀더인 것은 **`field_sprite` 구간**뿐이다 — 플레이어·주민·야생동물이
  도형이고 초상화 자리도 비어 있다. 파일이 오면 논리 에셋 ID 로 교체된다.

## 화면별 메모

### 정비 허브

- 좌측 보관함 상시 영역 (`소지금` + `수확물`·`재료`·`무기`·`소모품` 네 갈래),
  상단 기능 버튼 4개, 우하단 정비 종료 버튼.
- 제목 옆에 그날 밤의 습격 예고가 붙는다 (`raid_notices.hud_label`, `DEC-RUN-011`).
  캡처는 습격이 없는 1일차라 `오늘 밤 · 조용함` 이다.
- 종료 버튼 문구는 그날 습격 여부로 하나만 나온다 (`DEC-UI-014`). 1일차라
  `아침까지 잔다` 이고, 습격일이면 `밭을 정찰하러 간다` 가 대신 나온다.
- **`-filled` 는 개발 통로가 아니라 실제 플레이로 만들었다.** 세 칸을 거둬 토란
  1개를 팔고(10원) 천 자루를 사서(3원) `미끈 토란 주머니` 2개를 제작한 상태다.
  8/5 캡처는 `__dev.fillThrowables()` 로 채웠는데 그 통로는 지웠다.
- 셔터 뒤로 필드가 아주 옅게 남는다. 8/6 에 불투명도를 0.94 에서 0.985 로 올렸다 —
  0.94 로는 커진 HUD 표지판이 비쳐 `소지금` 과 겹쳐 읽혔다.

### 전투 전 대화

- `dialogue-modal.ts` 하나가 전투 전 대화와 투항 대화를 **함께** 그린다
  (`DEC-UI-010` — 같은 표시·입력 규칙). 투항 대화도 이 배치다.
- 선택지 두 번째가 흐리게 나온 것은 **자원 부족으로 못 고르는 상태**다
  (`수확물 10개 (보유 0)`). 불가능한 선택지 표시 방식이 여기 같이 보인다.
- 대화가 열려 있는 동안 전투가 멈춘다 (`DEC-INPUT-009`).
- **배치는 아직 A4 확정 전이다.** 전성민이 8/5 저녁에 새 배치를 정했고
  (아트 디렉션 12.2 A4 — 좌우 상반신, 하단 대사창, 두 인물 사이 선택지 말풍선)
  초상화 그림이 나오면 그때 다시 짠다. 지금 캡처는 **그 전 상태**다.

## 다시 찍는 방법

개발 빌드에서 정상 흐름으로 밟는다. 개발 통로(`__dev`)는 8/5 에 전부 지웠으므로
**심고 기다리고 거두는 것을 실제로 해야 한다.**

```
타이틀 시작 → 이름 입력 → 튜토리얼 건너뛰기 → 1일차 시작
가운데 줄 세 칸에 E 로 심는다 (칸 간격 200, 이동속도 260)
28초 기다린다 (가장 느린 작물이 씨앗 5 + 성장 22)
같은 칸을 E 로 거둔다 → 재배 60초가 끝나면 정비 허브
```

흐름만 밀고 싶으면 개발 빌드 콘솔에서 `__scenes.send()` 를 쓴다. 다만 그러면
보관함이 비어 있어 `-filled` 를 만들 수 없다.

```js
__scenes.send({ type: 'farming_time_expired' })                          // 정비 허브
__scenes.send({ type: 'maintenance_finished', intent: 'sleep_until_morning' })
__scenes.send({ type: 'confirm' })   // 밤 결과 → 2일차 시작
__scenes.send({ type: 'confirm' })   // 2일차 시작 → 재배
__scenes.send({ type: 'farming_time_expired' })
__scenes.send({ type: 'maintenance_finished', intent: 'scout_field' })   // 전투 전 대화
```
